# AstroSearch Observatory Mantis extension

A dependency-free dashboard panel for the live AstroSearch astronomy space.

- Extension id: `astrosearch.observatory`
- Panel: **AstroSearch Observatory**
- Permissions: `maps:read`, `selection:read`
- Backend: none
- Network access: none
- Writes: none

The panel provides a structured entry point to the Mega Atlas, semantic catalog, ICRS sky atlas, and TESS signal lab. It displays the curated review queues and scientific interpretation rules without changing source data.
